# Golden ERP UI Standard

Status: ACTIVE

Golden ERP surfaces are dense transaction workspaces, not marketing pages or collections of decorative cards.

## Required hierarchy

- Compact command header: identity, purpose, primary action.
- Small attention/status strip only when it supports a decision.
- One unified search/filter surface.
- A dominant worklist or primary transaction workspace.
- Contextual detail in a side sheet or predictable secondary pane.
- Shared design tokens and components; no parallel design system.

## Presentation rules

- Prefer spacing, typography and light dividers over card proliferation.
- Avoid gradients, oversized icons, excessive rounding and empty vertical space.
- Map raw enums and technical terms to localized business labels.
- Preserve exact financial values and ISO currency. Chart axes use a declared unit; tooltips show exact values.
- Keep primary actions dominant only when valid; communicate readiness otherwise.
- Contained table/list scrolling is acceptable. Page-level horizontal scrolling is not.
- Desktop verification targets: 1920x1080, 1440x900, 1366x768, 1024x768.

Rendered verification must be reported honestly. If no rendering/browser facility is available, record `AUTOMATED VISUAL VERIFICATION: UNAVAILABLE`; do not claim PASS.
